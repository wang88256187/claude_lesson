# 抢险救援标绘（第一版：手动标绘）

纯前端页面，不需要安装，也不需要联网：**直接双击 `index.html` 就能用**（Chrome 或 Edge）。
所有依赖都在本目录里：Leaflet 地图库在 `vendor/`，符号库在 `symbols.js`，适合内网或离线环境。

## 功能

| 功能 | 说明 |
|---|---|
| 符号面板 | 分四组：「泥石流常用」「GB/T 35649」「XF/T 3013」「扩充」。支持按名称、编码、子类文字搜索 |
| 点状标绘 | 单击放置，可以连续放置；放好后能拖动，也能调整旋转、大小、透明度 |
| 线状、面状标绘 | 依次单击各点，双击或按 Enter 结束，Esc 取消。选中后可以拖动顶点，右键删除顶点 |
| 线型渲染 | 按 GB/T 35649 附录 B、C 的样式沿线绘制重复图案，例如救援车辆行进路线的旗形、撤离线路的菱形、遭破坏道路的"×××"；事故控制区和蔓延区的箭头会自动朝内或朝外 |
| 属性编辑 | GB/T 35649 点状符号可以改标识文字，下拉里有标准列出的子类文字。另有注记（番号、单位）、人数、装备、任务、时间、备注。时间按 XF/T 3013 的格式，点"现在"自动填写，例如 `2026.09.29.0630` |
| 图廓 | 图名、制图时间、比例尺、指北针（XF 6.3.2）；图例根据已标绘的符号自动生成 |
| 撤销、重做 | Ctrl+Z / Ctrl+Y，最多保留 200 步 |
| 自动保存 | 标绘内容实时保存在本机浏览器里，刷新页面不会丢 |
| 保存、打开 | 导出和导入 GeoJSON 文件，可以与 GIS 软件互通。属性里的 `symbol` 字段对应符号库的 id |
| 打印、PDF | A4 横版，自动隐藏两侧面板 |
| 底图 | OSM 在线地图；**自定义瓦片地址**，用于接内网瓦片服务；**无底图网格**；**加载本地图片**，例如无人机正射影像、扫描地图，会铺满当前视野 |
| 演示数据 | 虚构的泥石流救援态势（33 个要素），可用来熟悉操作 |

## 快捷键

| 键 | 作用 |
|---|---|
| Enter | 结束当前线或面的绘制 |
| Esc | 取消绘制，或取消选中 |
| Delete | 删除选中要素 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |

## 数据安全

- 标绘数据只保存在本机浏览器和你导出的文件里，页面不会上传任何数据。
- 选择 OSM 底图时，浏览器会去请求公网地图瓦片（只下载地图图片，不上传标绘内容）。涉及真实任务时，请改用**内网瓦片**、**本地图片**或**无底图**。

## 已知限制

- 本地图片底图不会随文件一起保存；只能铺满当前视野，还不能精确配准坐标。
- 线状符号的装饰图案按屏幕像素间隔排列，缩放地图时会重新排布。这符合标准"应自行掌握合理间距，间断进行标记"的要求。
- 自定义瓦片地址需要是 `{z}/{x}/{y}` 格式的 Web 墨卡托瓦片。

## 智能标图（一句话标图）

在右侧「智能标图」框输入口述指令，例如：

> 二中队从集结地沿救援车辆行进路线出发，向堆积区东侧搜救，堆积区东侧新发现被困群众 4 人

点「解析」（或按 Ctrl+Enter）后，大模型把指令转成标图操作。结果先在图上用**蓝色虚线预览**，可以逐条勾选，确认后点「写入地图」；写入后整批可以 **Ctrl+Z 一步撤销**。

- **支持的操作**：新增点、线、面；修改已有要素的注记、人数、标识文字；删除要素。
- **定位方式**：大模型只负责给出"参照物 + 方位 + 距离"，例如"前指东北 300 米"，坐标由程序计算，不让模型编造经纬度。参照物可以是：
  - 图上已有的要素，按注记或名称匹配
  - 当前视图中心
  - 你用「放参考点」在图上点下的 P1、P2…
- **沿线行进**：可以引用已有线路，例如"沿救援车辆行进路线"。
- **朝向**：会换算成符号的旋转角度，例如进攻方向"向东北"。
- **模型问题**：模型无法确定的内容，会以"？"问题的形式列出来，不会乱猜。

### 连接大模型

智能标图需要一个 OpenAI 兼容接口（`/v1/chat/completions`）。推荐用上一级目录的 `server.py` 启动，它负责提供页面，并把请求转发给模型（只用 Python 标准库，不需要安装任何东西）：

```bash
cd rescue_plotting
# 本地大模型（vLLM / Xinference / LM Studio 等）
python server.py --llm-url http://127.0.0.1:8000/v1 --model qwen2.5-14b-instruct
# Ollama
python server.py --llm-url http://127.0.0.1:11434/v1 --model qwen2.5:14b
# 然后浏览器打开 http://127.0.0.1:8765
```

- 如果直接双击 `index.html` 打开，可以在「设置」里选"浏览器直连"，填入接口地址和模型名。这种方式需要模型服务允许跨域，例如 Ollama 要设置 `OLLAMA_ORIGINS=*`。
- **模型建议**：14B 及以上的中文指令模型效果更稳，例如 Qwen2.5-14B/32B-Instruct、Qwen3 系列。提示词加符号目录约 4k tokens，上下文 8k 以上即可。
- **推理模型（Qwen3 等）**：启动时加 `--no-think` 关闭思考过程。实测 Qwen3.6-27B 开启思考每条 40~170 秒，关闭后 4~9 秒；在当前提示词下，两种模式对 4 条测试指令都解析正确。
- **支持的操作**：新增、修改（注记/人数/标识文字）、移动（把已有的点状力量或装备挪到新位置）、删除。
- **数据安全**：`server.py` 默认只监听本机（127.0.0.1）。转发的内容只有指令文字和图上要素的名称、相对位置（米），不含经纬度。**真实任务请只接内网模型。**
