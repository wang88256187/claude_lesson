# 抢险救援标绘符号库（泥石流场景）v0.3.0

这是"智能标图工具"的基础符号库，共 176 个符号，打开 `preview.html` 可以查看全部。

| 部分 | 数量 | 来源 | 说明 |
|---|---|---|---|
| **GB/T 35649-2017** 突发事件应急标绘符号 | 72 | 国家标准全文 | 点状 60 个：主体图形从标准原图**自动矢量化**，外框和文字按标准重建。线状 9 个、面状 3 个：按附录 B、C 的像素参数绘制 |
| 泥石流场景预设 | 23 | GB/T 35649 的符号 + 标准"子类文字标识" | 例如 A10400 地质灾害换成"泥石流""滑坡""崩塌"，A21300 换成"公路设施""桥梁隧道" |
| **XF/T 3013-2020** 消防救援队伍常用标号 | 65 | 行业标准全文 | 指挥部、指挥员、人员、集结地、车辆器材、战斗行动（前身是武警消防部队的标号体系） |
| 自定义补充 | 16 | 按 GB/T 35649 第 7 章的扩充原则设计 | 只保留两项标准都没有的：失联人员、不稳定斜坡、泥石流流向、堆积区等 |

预览页里的标签颜色：**绿色**表示标准原有符号或标准子类文字，**灰色**表示扩充的自定义符号。

## 怎么选符号（泥石流场景）

| 要标的内容 | 用哪个符号 |
|---|---|
| 泥石流、滑坡、崩塌发生点 | `GB-A10400-泥石流` / `-滑坡` / `-崩塌` |
| 山洪、暴雨 | `GB-A10100-山洪`、`GB-A10200-暴雨` |
| 道路、桥梁、房屋、电力、通信受损 | `GB-A21300-公路设施` / `-桥梁隧道` / `-建筑垮塌` / `-电力设施` / `-通讯设施` |
| 现场指挥部 | `GB-D10100-地质灾害`（国标），或 `XF-6.1.12` 旗形（队伍内部标图） |
| 武警、军队、救援队 | `GB-D20200` 武警、`GB-D20100` 军队、`GB-D20400` 救援队 |
| 分队、人员、侦察组、集结地 | `XF-6.1.x` |
| 被困人员 | `XF-6.3.22` |
| 安置点、物资、临时医疗 | `GB-D10200-临时安置` / `-物资发放` / `-临时医疗`，`GB-D60100` 避难场所 |
| 救援车辆行进路线、群众撤离路线 | `GB-E30100`、`GB-E30200` |
| 道路损毁段、危险路段 | `GB-E20500`、`GB-E20400` |
| 警戒区、事故控制区、蔓延区 | `GB-F10100`、`GB-F10200`、`GB-F10300` |
| 计划路线、救援推进方向、撤退路线 | `XF-6.3.17`、`XF-6.3.18`、`XF-6.3.21` |
| 泥石流流向、堆积区、核心危险区 | 自定义 `X-L01`、`X-F01`、`X-F02` |

上表中"国标"和"队伍内部标图"两种写法都能用。对外通报、与地方应急部门协同时，建议优先用 GB/T 35649；队伍内部的兵力部署和行动，用 XF/T 3013。

## GB/T 35649 的主要规则

所有规则都已写入 `symbols.json` 的 `rules.gb35649` 字段。

- **外框**：突发事件用圆角正方形，危险源、防护目标、应急保障资源用直角正方形。
- **尺寸**：最小 32×32 像素，文字区 8×32 像素；标识文字用黑体加粗，2~4 个汉字，放在外框下部 1/4。
- **颜色**（表 3）
  - 突发事件：红 (255,0,0)
  - 危险源：黄 (255,255,0)
  - 防护目标：蓝 (0,0,255)
  - 应急保障资源：绿 (0,255,0)
  - 线状和面状：一律红色
  - 标准印刷稿里的实际颜色另存在 `color_print` 字段，屏幕显示时可以切换。
- **编码**：6 位，格式为"大类字母 + 中类 + 小类 + 子类"，例如 `A10400` 表示"突发事件 - 自然灾害 - 地质灾害"。
- **引线标注**：红色轮廓、白杏仁色填充、黑色宋体 12 号；符号还应提供透明度设置。

## XF/T 3013 的主要规则

写入 `rules.xf3013` 字段，代字表写入 `codes_xf3013` 字段。

- **颜色**：队伍、人员、车辆、行动用红色，器材和建筑用黑色，水源用蓝色。
- **线形**：实际部署和行动用实线，计划的用虚线；级别、人员、车辆的轮廓用粗实线。
- **注记**：机关名称写作"地名+代字"，例如"江苏 XFZOD"；参数写在标号下方，用"/"隔开；时间写作 `2019.06.06.0808`。

重新生成：

```bash
pip install pymupdf numpy scipy potracer   # 只有重新提取时才需要
python tools/extract_gb35649.py ../refs/gbt35649.pdf   # 可选：重新矢量化
python build_symbols.py
```

新增子类预设，在 `build_symbols.py` 的 `PRESETS` 里加一行即可，例如 `P("A10400", "地面沉降")`。

## 关于武警部队标号

- GB/T 35649 里有 **D20200「武警」** 和 D20100「军队」两个符号，可以直接用于对外标绘。
- 武警部队内部的标图规定（《作战标图规定》的补充规定）没有公开，本库不包含。部队的级别和番号，可以先用 XF/T 3013 的盾形队标加本单位代字表示（`xf3013.shield_org("代字")`）。
- 单位的正式标号请用下面的导入工具在内网或离线环境录入，不要上传到公网服务。

## 导入本单位标号

把本单位下发的标号（扫描件、截图或图片）转成矢量符号，在标绘页面的「本单位」分组中使用。**全程离线**，导入结果只保存在本机：`symbols/local/` 和 `app/local_symbols.js`，这两处已加入 `.gitignore`，不会被提交到代码仓库。

### 准备（一次性）

内网电脑需要 Python 3.9 以上，并安装依赖：

```bash
pip install -r symbols/tools/requirements.txt
```

内网不能联网时，先在外网电脑上执行 `pip download -r requirements.txt -d wheels`，把 `wheels` 文件夹拷进内网，再执行 `pip install --no-index --find-links wheels -r requirements.txt`。

### 方式一：扫描件框选（推荐）

1. 如果资料是 PDF，先转成图片：
   ```bash
   python symbols/tools/import_symbols.py pdf2png 规定.pdf 页面图片/ --dpi 200
   ```
2. 用浏览器打开 `app/tools/cropper.html`（标号采集页），点「打开扫描件/图片」载入页面图片。
3. 在图上**拖动鼠标框选**一个标号。只框图形本身，不要框进表格线和说明文字。
4. 在右侧填写编号、名称、类型（点/线/面）、分类。编号会自动递增。线状、面状符号还要选线型（实线/虚线/点划线）和箭头；地图上按这些设置绘制，截取的图片只作预览。
5. 全部框完后点「导出采集结果」，得到 `标号采集结果.json`，然后运行：
   ```bash
   python symbols/tools/import_symbols.py 标号采集结果.json --source "某部常用标号（2024版）" --preview
   ```
6. 打开 `symbols/local/preview.html` 核对效果，然后刷新标绘页面，符号就会出现在最前面的「本单位」分组里。

### 方式二：图片文件夹

每个标号一张图片，文件名写成"编号_名称"，例如 `ZB-01_前进指挥所.png`。如果还要指定类型、分类、颜色等，先生成清单模板，用 Excel 或 WPS 填好后再导入：

```bash
python symbols/tools/import_symbols.py init 标号图片/        # 生成 manifest.csv
python symbols/tools/import_symbols.py 标号图片/ --preview
```

### 常用参数

| 参数 | 作用 |
|---|---|
| `--source "名称"` | 符号来源说明，显示在页面上 |
| `--snap` | 把颜色吸附到标准色（红/黑/蓝/绿/黄/粉红），扫描件偏色严重时使用 |
| `--append` | 追加到已有的本单位库（同编号的会被替换）；默认是覆盖 |
| `--preview` | 生成 `symbols/local/preview.html` 核对效果 |

### 处理方式与注意事项

- **自动处理**：
  - 以图片四周的颜色估计纸张底色，用自适应阈值分出笔迹，能兼容泛黄、泛灰的扫描件。
  - 自动识别颜色，多色标号会分层矢量化，比如红色图形加黑色代字。
  - 自动去除细小噪点。
- **扫描分辨率**：建议 200 dpi 以上。标号里的小字（如代字"XZB"）分辨率不足时会变形，这种情况可以重新扫描，或截取更清晰的图。
- **结果不理想时**：单色标号在清单里设 `mode=mono` 并指定 `color`；颜色偏差大就加 `--snap`。
- **保密**：本单位标号属于内部资料。采集页和导入脚本都不联网，但导出的 JSON 和生成的文件同样要按内部资料管理，不要外传，也不要提交到代码仓库。
- **智能标图**：智能标图会把本单位符号的名称发给大模型，**只能接内网部署的模型**。

## 质量说明

- **GB/T 35649 点状符号**：主体图形由标准原图自动矢量化，已经逐个和原图比对过。外框的圆角和线宽用的是印刷稿实测值（圆角约 6.9、线宽 1.4，按 32 单位计）。标准正文写的是"最小值"（圆角 5 像素、边框 1 像素），两者不冲突。
- **GB/T 35649 线状和面状符号**：按附录里的像素参数绘制。其中生态隔离线的箭形交叉等少数细节是按图示复原的。
- **XF/T 3013**：按原图重绘，抢险救援车车身内的图形、链锯、起重气垫这几个细节是目测复原的，正式使用前请对照原文核对。
